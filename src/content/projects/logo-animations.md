## Why logos need to move

A static logo is a promise. A moving one is proof. This ongoing series takes finished identity marks and gives them a behaviour — the way they'd actually appear in the world: booting up an app, closing out a video, stamping a social post.

## The process

Every animation starts from the construction logic already inside the mark — the stroke order, the negative space, the grid it was built on — so the motion feels like it was always part of the design, not bolted on afterwards.

Timing is tuned frame by frame against sound design, because a logo animation lives or dies in the first half-second.

## The result

A growing library of motion identities, each one built to be dropped into a reel, an app splash screen, or a fifteen-second ad with zero extra work.
